# Çelikel Oto Servis web sitesi

Yarımburgaz / Küçükçekmece'deki Çelikel Oto Servis'in tanıtım sitesi.

- `index.html`: sitenin tamamı (tek sayfa)
- `favicon.svg`: tarayıcı sekmesindeki simge
- `logo/`: logo dosyaları (yatay, dikey, koyu zemin, amblem; SVG ve PNG)

Site GitHub Pages ile yayınlanır: `main` dalına gönderilen her değişiklik birkaç dakika içinde yayına girer.

Telefon, çalışma saatleri ve kapalı günler `index.html` dosyasının sonundaki `AYAR` satırından değiştirilebilir.
